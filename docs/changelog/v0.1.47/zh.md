### 武器 / 手感

- 旋风甩出去的轻武器会算成旋风那方的，不会误伤自己人
- 投掷型武器不再因旋风造成超快的连续命中
- 重型武器砸中人时，被砸的人飞出去的速度方向将根据双方位置决定
- 只能捡到地面上的武器

### 修复

- 修了闯关模式里队伍存活判断不准的问题
- 闯关模式百叶窗动画改纯黑
- 修复 3D 模型与 2D 角色/道具互相“嵌入/穿插”的遮挡问题：现在按 Z 前后正确遮挡，靠前(Z 大)的 2D 会完全盖住靠后的 3D，靠后的 2D 也会被靠前的 3D 完全遮住 (未校对)
