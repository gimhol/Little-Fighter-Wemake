"地形与联机"

### 新增

- 地形数据新增 `one_way` / `cliff` / `cliff_frame` / `cliff_respawn_y`：支持单向平台、坠崖判定与坠崖后的重生点。

### 调整

- 防御 + 下可以按地形配置向下穿过单向平台。
- 奔跑限制更严格。
- 修正拾取武器时的一些判定。
- 联机界面（连接弹窗、房间列表、房间页）继续调整按钮文案与布局。

### 修复

- 浏览器 / 扩展 / B 站 Toy 等非桌面壳不再渲染顶栏拖拽层，画面顶部的按钮（房间列表 / 房间页的操作）不再被它挡住；Electron / Wails 仍保留窗口拖动。
