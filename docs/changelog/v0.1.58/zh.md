### 新东西

- 联机服务器管理页面：浏览器打开 `http://<服务器地址>:<端口>/admin`（桌面客户端托盘「打开管理页面」一键进入）
  - 总览：在线客户端 / 对局中玩家 / 管理员连接 / 房间数 / 运行时长 / 内存
  - 房间列表与详情（可关闭房间）、客户端列表（可踢出）、玩家 token 列表（可复制 / 吊销）、排行榜查询、接口清单
  - 自动刷新（默认 5 秒，可调）；管理接口需要管理员 token，桌面客户端首次启动会自动生成并存进数据目录的 `admin.json`，页面上直接填、或用 `?token=<token>` 打开都可以

### 调整

- 修复：桌面客户端托盘「开启联机服务器」后服务器立刻退出（内置服务端缺少 `__GIT_COMMIT__` 等构建期常量，一启动就报错）
- 修复：桌面端打包不再漏掉服务端的构建信息注入，日志里能看到联机服务器的版本与提交号
