
# LF2 完整出招表 v2.0a

> 按键定义
>
> - D = 防御，A = 攻击，J = 跳跃
> - → 向右，↑向上，↓向下；`…` 表示最后一个键连按
> - **Catch = 抓住敌人（近身抓取）**
> - `@`：持续消耗MP；`+8hp`：释放时扣自身血量

## 一、AI指令（队友控制）

| 指令 | 按键 | 说明     |
| ---- | ---- | -------- |
| Come | D+J  | 过来     |
| Stay | D+A  | 原地待命 |
| Move | D+→ | 向前移动 |
