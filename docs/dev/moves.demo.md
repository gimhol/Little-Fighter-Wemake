# 出招表演示：招式特征表

> 本文记录 `lf2s/origin/extra_data/moves/*.moves.json5` 中每招演示的「特征」（布置 / 偏移 / 命中情况），方便后续改动时快速查表，不用重跑一遍。
>
> 相关代码：`src/LFW/ui/component/MoveTable/MoveTableLogic.ts`、`src/LFW/defines/IMoveListData.ts`

## 一、通用规则

- **演示窗口**：`move_table_panel.png` 的镂空区 `x 399..780 / y 34..415`（381×381）。窗口**外**被面板挡住，任何实体跑出去就看不见。
- **角色默认位**：`ACTOR_X = 589.5`（窗口横向正中），z 取背景景深中点 `-342`；MP 拉满、头顶常驻按键指示器（`ctrl_visible`）。
- **每招自带 `entities`**：招式自己负责敌人/队友阵容，不再继承列表级（列表级 `entities` 已全部删除）——改一招不会影响同角色其他招。
- **敌人默认排一条水平直线**（同一 z）：`dx 50/100/150`（贴脸三连）；需要弹道飞行距离的远程招用 `50/100/150` 之外的更远排法（见各招）。
- **`dx`（相对窗口中心的起点偏移，负数=偏左）**：位移大的招按「实测位移的一半取负」给值，让整段位移以窗口中心对称；前冲的招如果攻击帧比冲刺慢，就把敌人排得更远（如 `150/200/250`）保证打得到。
- **实体夹取**：所有演示实体（含角色）每帧把 x 夹在窗口内（含 `_entity_fit` 等比压缩兜底），被击退也不会滑到面板后面。
- **队伍**：角色固定 team 1；`entities[].team` 不写 = team 2（敌人），写 `"1"` = 队友。
- **按键序列**：一律 `keydowns` + `keyups`（按住 100ms 松开）；连按用 `loop` + `gap`（见 `moves.punch`）。「冲刺」= 双击方向键（两次 down 间隔 < 30 tick），不是长按。
- **启动 / 结束延迟（数据字段）**：`start_delay` = 演示开始前等待（列表级，除 Template 保持 1000 外全角色 500）；`end_delay` = 演示结束到自动重播的等待（列表级，全角色 2000）。单条招式可用同名字段覆盖（`IMoveInfo.start_delay/end_delay`）。招式结束后**自动重播**（无限循环）。
- **队友血条**：`stat_bar: true` → 代码同时把 `key_role` 打开（引擎只在 `key_role` 为真时画浮动血条）+ `stat_bar_type = Float`；`hp: N` 只改当前血量，上限仍取角色数据。
- **吸血类（Bat 吸血蝙蝠）**：要看回血就把**角色自己**的条拿出来 —— `hp: 100, stat_bar: true`。吸血 = 每只追人蝙蝠命中后按伤害的 20% 回给 Bat（`VALUE_STEAL`）；蝙蝠数量 = `max(3, 敌人数)`（按敌人数生成、一只盯一个），敌人**围一圈**站就能看到四面都有蝙蝠飞过去（不要求全中）。
- **抓人教学（Template 连击 → 抓起 → 丢出）**：3 下普攻把敌人打进**眩晕**（帧 226-229 / state 16，窗口约 1.2s）→ 停下来让观众看清 → 走过去**碰到即自动抓**（抓住不需要按键，走路撞上去就行）→ 抓中按 A 出拳（每次 15）、**按住前（`>`）再按 A** = 丢出（帧 232-234）。⚠ 抱住有时限（约 1.9s，超时自动松手），节奏要紧凑：连击 0-900ms → 走近 1400 → 抓打 1650/2050/2450 → 丢 2750。
- **范围/扩散类招式**（爆炸、音波、围殴、召唤）：演示角色站窗口正中（`dx: 0`），其他对象围着角色摆一圈——用 `dz` 拉开屏幕纵向（屏幕 y = -dz/2，好动范围 ±126）。常用布局：**贴身环 6 个**（`±60` + `±35,dz±55`，火艒大轟炸 / Julian 化為烏有）、**大环 6 个**（`±110` + `±60,dz±100`，Henry 魔王之樂章）、**中环 6 个**（`±70` + `±45,dz±70`，Jan 惡魔審判）、**扇形 5 个**（`140` + `100,dz±90` + `40,dz±130`，Bat 吸血蝙蝠 / Firzen 天厄滅絕）。这类演示**不要求全中**（恶魔审判是随机落点、蝙蝠只有部分会飞向目标）。
- **多段飞镖/箭矢类**（Rudolf 五連鏢 `D>A…`、Henry 五連矢 `D J A…`）：敌人改成沿 **Z 轴一排**（同一个 x，dz `0/±40/±80`，屏幕上就是竖着一列）——散布飞镖/箭矢会一个个各自吃到目标，实测五个全中；`dz` 超过 ±100 就打不到了。
- **追击段（+A）类**（Mark 冲撞拳 `D+>+A+A`、Justin 狼拳 `D+v+A…`）：第一段打完要**继续按 A** 才有后续段 —— seq 在首段之后补 `a` 连按（`loop` + `gap`，首按约 400ms），只按一次只有一段（伤害差一半以上）。敌人排「贴身类」的紧凑一排（间距 20px）。
- **招式列表改用 ScrollView**（2026-09-25）：列表区 `move_list_scroll`（视口 700×196，行高 24、行宽 420——按最长文本量出的宽度，行池 `move_row` ×24）内嵌 `move_list_content`，所有招式一次性列出、超出即可滚动（滚轮 / 拖拽）；切换招式时当前行自动获焦（`▶` 行有焦点底色）并滚入视野，鼠标悬停或点击某一行即可切换到该招（拖拽松开不会误触切换）。
- **列表显示**：未开 `LF2_NET` 作弊码时隐藏 30-39 / 50-59 的角色（出招表里看不到）。
