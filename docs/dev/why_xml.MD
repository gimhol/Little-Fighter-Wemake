# 为什么想要支持XML

本来支持json/json5，这种格式其实不方便人直接进行编辑，下图会有个比较直观的比较。

![aeedcf11a0c3f300c97f48a6ff5a8e0e.png](../image/aeedcf11a0c3f300c97f48a6ff5a8e0e.png)

很明显，格式化后，json/json5的数据会变得非常长一条，一屏幕内能展示的内容很少，而xml则紧凑的多。

另外我实在不太满意原始lf2数据格式，它在“标准化”方面有些问题（比如，有时候冒号，有时候又不要……）

当然，如果实现了编辑器，数据格式倒是不重要。

而要实现个好用的编辑器还是非常麻烦，尤其在当前未稳定的情况下。
