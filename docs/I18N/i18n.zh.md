# 多语言（i18n）资源导览

本文档帮助快速定位游戏内所有翻译词条的位置、当前支持的语言，以及如何新增语言。

---

## 1. 快速定位：词条文件在哪

| 覆盖界面 | 文件路径 | 说明 |
| --- | --- | --- |
| **启动界面**（点击继续 / 声音警告 / 版权长文 / 附加模组按钮） | `public/builtin_data/launch/strings.json5` | 所有语言块内嵌在**同一个文件** |
| **游戏主界面/设置/按键/选人/计分板/教学**（prel 包） | `lf2s/origin/prel_data/strings.json5` | 英文 base、简繁中文、语言别名 |
| 同上（各语言的独立词条文件） | `lf2s/origin/prel_data/<lang>.i18n.json5` | **每个语言一个文件**（es/fr/ja/ko/pt/ru/nl/de/pl/it） |
| data 包（`lf2s/origin/game_data`） | （无词条文件） | 数据包不含文案 |

> 注意：**两套词条是各自独立维护、不会互相同步的**：
>
> - `init.*`（启动界面文案）只存在于 `public/builtin_data/launch/strings.json5`，prel 的语言文件里**没有**。
> - `settings / tutorial.* / score_board.* / main_page.*` 等只存在于 prel，builtin 里**没有**。
>
> 新增一种语言时，**两处都要改**（除非只关心其中一类界面）。

## 2. 词条文件结构

### launch：`public/builtin_data/launch/strings.json5`

```json5
{
  "": { ... },            // 英文 base（兜底语言）
  "zh-hans": { ... },     // 简体中文
  "zh-hant": { ... },     // 繁体中文
  fr: { ... },            // 其它语言各一块
  ...
  "zh-cn": "zh-hans",     // ↓ 下面全是语言别名（地区码 → 语言）
  "fr-fr": "fr",
  ...
}
```

### prel：`lf2s/origin/prel_data/`

- `strings.json5` —— 结构同上（`""`/`zh-hans`/`zh-hant` 内嵌 + 别名表），**不含** fr/es/... 词条。
- `<lang>.i18n.json5` —— 每语言一个，形如：

```json5
{
  "de": {
    settings: "Einstellungen",
    "tutorial.dialog_0": [ "行1", "行2", ... ],   // 数组 = 多行对话框
    ...
    "": "",                                        // 文件尾占位
  },
}
```

**词条 value 类型**：

- `string`：单行文本（支持 `\n`）。
- `string[]`：教学对话框 `tutorial.dialog_*` 等多行内容。
- 缺失的语言 / 缺失的 key → 自动回退到英文 base（`""`）。

### 常用语言别名（地区码 → 语言）

- 中文：`zh/zh-cn/zh-sg/zh-my/zh-chs` → `zh-hans`；`zh-tw/zh-hk/zh-mo/zh-cht` → `zh-hant`
- 法语：`fr-fr/fr-ca/fr-be/fr-ch` → `fr`
- 西班牙语：`es-es/es-mx/es-ar` → `es`
- 葡萄牙语：`pt-br/pt-pt` → `pt`
- 日语 `ja-jp` → `ja`
- 韩语 `ko-kr` → `ko`
- 俄语 `ru-ru` → `ru`
- 荷兰语：`nl-nl/nl-be` → `nl`
- 德语：`de-de/de-at/de-ch` → `de`
- 波兰语 `pl-pl` → `pl`
- 意大利语：`it-it/it-ch` → `it`

## 4. 新增一种语言的步骤

以新增「土耳其语（`tr`）」为例。

### A. 启动界面（launch）

编辑 `public/builtin_data/launch/strings.json5`：

1. 在 `zh-hant` 块之后、`zh: "zh-hans"` 之前加语言块（5 个词条）：

   ```json5
   tr: {
     "init.tap_any_place_to_launch": "...",
     "init.sound_warning": "...",
     "init.long_description": "...\n\nÇeviren: Deepseek v4 flash, ...",
     extra_data: "...",
     add_mods: "...",
   },
   ```

2. 在文件尾部别名表加：`"tr-tr": "tr",`

### B. 游戏内（prel）

1. 复制 `lf2s/origin/prel_data/fr.i18n.json5` 为 `tr.i18n.json5`，把 `"fr"` 改为 `"tr"`，翻译各词条（`old_ending_*`/`gim_ending_*` 可跳过不译）。
2. 在 `lf2s/origin/prel_data/strings.json5` 别名表加：`"tr-tr": "tr",`
3. **打包生效**：`npm run build:prel`（把 origin/prel_data 打包进 `public/prel.zip`）。
   - launch（builtin_data）是直接目录资源，本地 dev 无需打包即可生效；发布时需要一并打进产物。

---

## 5. 注意事项

- **别把词条留空字符串** `""`：I18N 对存在的空字符串会原样返回（显示空白），而不是回退英文。要么给翻译，要么直接删掉该 key。
- **`old_ending_*` / `gim_ending_*`（结局长文本）约定不翻译**，保持 base 原文。
- **除英文、简中、繁中外，其余语言均未人工校对**（机器/AI 翻译）：launch 的 `init.long_description` 末尾已按各语言附免责声明（如 “Übersetzt von Deepseek v4 flash, nicht korrekturgelesen...”）；prel 的 `*.i18n.json5` 同样未校对，如需发布请先人工校对。
- 保留游戏符号与排版标记：`ⒶⒿⒹ`、`⬅➡⬆⬇←→↑↓`、`【】`、`\n`、全角冒号（`char_menu.player_colon` 用 `：`）等，勿改动。
- URL（`goto_github_url`）等非文本 key 无需翻译，直接复制。
