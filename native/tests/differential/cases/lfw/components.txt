# 4AU：组件族第一批（FocusBehavior / HoverBehavior / OpacityHover / SineOpacity / FadeInOpacity）
# FocusBehavior：默认行为聚焦/失焦换底色（大小写/空白归一）；未知行为无动作；空串回 default
nmk fb1 - o 6 id s "fb1" pos a 3 n 0 n 0 n 0 size a 3 n 2 n 2 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1 component a 1 o 3 cls s "FocusBehavior" id s "fb" properties o 1 behavior s "DEFAULT "
lcomp fb1
nrd fb1 color
nset fb1 focused 1
nrd fb1 color
nset fb1 focused 0
nrd fb1 color
nmk fb2 - o 6 id s "fb2" pos a 3 n 0 n 0 n 0 size a 3 n 2 n 2 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1 component a 1 o 3 cls s "FocusBehavior" id s "fb2c" properties o 1 behavior s " other "

nrd fb2 color
