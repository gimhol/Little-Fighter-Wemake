# Picture：set_src 走 UIImgLoader（img_key 带 dw/dh），load 后 image 落节点并 resize(w/scale)
imgset p.png?x=h:,,,,10,20,0,0 o 4 w n 10 h n 20 scale n 2 src s "p.png"
nmk p1 - o 6 id s "p1" pos a 3 n 0 n 0 n 0 size a 3 n 10 n 20 n 1 center a 3 n 0 n 0 n 0 scale a 3 n 1 n 1 n 1 component a 1 o 4 cls s "Picture" id s "p1c" args a 0 properties o 0
pic p1 rd
pic p1 src p.png
pic p1 rd
nrd p1 size
pic p1 setw 7
pic p1 rd
imgset q.png?x=h:,,,,7,10,0,0 o 4 w n 7 h n 10 scale n 1 src s "q.png"
pic p1 src q.png
pic p1 rd
pic p1 seth 30
pic p1 rd
