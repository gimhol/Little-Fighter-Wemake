# 分组：Reachable.group() 从 root 向上找同名 ReachableGroup（root=rg1 自身 ⇒ 命中；g2 ⇒ u）
reach re1 rd
reach re3 rd
reach rg1 grd
nlife rg1 start
reach rg1 grd

# 导航：R 从无焦点开始取最左（re3），随后 re1、re5；L 回退；U 在 lr 组直接 return
nrd re1 foc
nkey rg1 down R KeyR
nrd re3 foc
nkey rg1 down R KeyR
nrd re1 foc
nkey rg1 down R KeyR
nrd re5 foc
nkey rg1 down L KeyL
nrd re1 foc
nkey rg1 down U KeyU
nrd re1 foc

# 可见过滤：隐藏 re2 后从 re1 前进到 re5
nset re2 visible 0
nkey rg1 down R KeyR
nrd re5 foc
nset re2 visible 1

# 禁用过滤：禁用 re2 后从 re5 前进应回卷到 re3（而不是 re2）
nset re2 disabled 1
nkey rg1 down R KeyR
nrd re3 foc
nset re2 disabled 0

# binded_layout（pad）不可见/禁用时按键无反应
nset pad visible 0
nkey rg1 down R KeyR
nrd re3 foc
nset pad visible 1
nset pad disabled 1
nkey rg1 down R KeyR
nrd re3 foc
nset pad disabled 0
