## 遥控技术

在设计某特效时，为了避免受到一般战斗的干扰，避开使用一般战斗区域，使特效能正常进行，而设计的区域通常会在天空或地底。

若同时有多个特效，为了避免其他特效的影响，就会将天空或地底划分多个频道来使用。

由于其 itr 及 bdy 使用区域与正常区域不同，因此称为**遥控**。

## 漂浮定位

此为使用 dvy 的上下来固定位置，并非 dvy 的 550。

- 像是 type 3 就不会受到「重力」影响，只要相同的正负 dvy 就可以漂浮了。
- 但是 type 0 就会有无形的 dvy: 1.7 的重力影响。
- （type 4 为 dvy: 0.85；type 6 为 dvy: 1.133（17/15））
- 由于 dvy 无法写入小数点，因此配合 wait 来修正。

**type 0 的重力：**

| dvy | 换算重力 |
| --- | -------- |
| -5 | -3.3 |
| -4 | -2.3 |
| -3 | -1.3 |
| -2 | -0.3 |
| -1 | 0.7 |
| 0 | 1.7 |
| 1 | 2.7 |

**因此：**

| dvy | 时间比例 | 重力 × 时间 |
| --- | -------- | ----------- |
| -1 | 3 | 0.7 × 3 = 2.1 |
| -2 | 7 | -0.3 × 7 = -2.1 |
| 1 | 1 | 2.7 × 1 = 2.7 |
| -2 | 9 | -0.3 × 9 = -2.7 |
| 0 | 3 | 1.7 × 3 = 5.1 |
| -2 | 17 | -0.3 × 17 = -5.1 |
| 0 | 1 | 1.7 × 1 = 1.7 |
| -1 | 1 | 0.7 × 1 = 0.7 |
| -2 | 8 | -0.3 × 8 = -2.4 |

所以说，只要调整时间比例，令总和为 0 就可以漂浮了。像这样写（总时间 40）：

```text
frame 300 wait: 11 next: 301 dvy: -1
frame 301 wait: 27 next: 300 dvy: -2
```
