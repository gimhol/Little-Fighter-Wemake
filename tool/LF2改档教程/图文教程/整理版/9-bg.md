## 基本信息

取自 hkc 的 bg：

```text
name: HK_Coliseum
width: 794  zboundary: 316 442
shadow: bg\sys\hkc\s.bmp  shadowsize: 37 9
```

| 字段 | 说明 |
| ---- | ---- |
| name | 地图名称 |
| width | 地图宽 |
| zboundary | 上下边界（此处需取 2 个值） |
| shadow | 影子 |
| shadowsize | 影子大小（此处取宽高 2 个值，人物会站在中间） |

## 第一组用法：图片

```text
layer:
  bg\sys\hkc\back2.bmp（图片路径）
  transparency:
  width:
  x:
  y:
  loop:
  cc:
  c1:
  c2:
layer_end
```

| 字段 | 说明 |
| ---- | ---- |
| layer | 图层开始 |
| transparency | 0 = 图片的黑色部分为不透明；1 = 图片的黑色部分做透明处理 |
| width | 宽，用来做立体效果，一般设定值会比地图宽小。<br>例：狮子山森林的宽 3200，而 forestt 背景 width 设 2900。<br>（2900-800）/（3200-800）= 7/8，约画面向右 8 格时（= 场地左移），forestt 背景就要向左移 7 格。<br>例：forests 背景 width 设 800。<br>（800-800）/（3200-800）= 0，表示这个背景固定不动 |
| x / y | 位置。为了达到立体效果，width 与 x 之间有密切关系。<br>像是狮子山森林放在最右边才出现的 forestm4 背景：<br>forestm4 图宽 184，x: 1216，width: 1400。<br>1216 + 184 = 1400，表示画面移到最右边时，图片刚好贴在最右侧 |
| loop | 循环。向右每多少 px 重复贴这张图（只能水平贴） |
| cc / c1 / c2 | 动态图片。以 hkc 为例：<br>cc: 16 c1: 0 c2: 7<br>cc: 16 c1: 8 c2: 15<br>表示动画循环时间为 16 TUs；back2 在循环的第 0 ~ 7 frame 显示；back22 在循环的第 8 ~ 15 frame 显示 |

> [!NOTE] layer_end 图层结束（注意！没有冒号）。

## 第二组用法：填满色彩

```text
layer:
  （图片路径，任意一张图就可以了）
  rect:
  x:
  y:
  width:
  height:
layer_end
```

| 字段 | 说明 |
| ---- | ---- |
| rect | 色码（底下介绍） |
| x / y | 位置 |
| width / height | 宽与高（这部分不能做立体效果，只能在画面中固定某区域填满） |

> 感谢 ↖吾≠叶↘ 提供算式…
>
> - RGB 换算回 rect，不考虑溢位。
> - 若输入 16 进制（前面加 0x 或 0X）或 8 进制（前面加 0），会帮你转回 10 进制。
> - rect 转 rgb，限输入 10 进制。

**如何换算 10 进制与 16 进制：** 到附属应用程序，开小算盘（计算器），检视 → 切换到工程型。

**如何找到颜色代码：** 到附属应用程序，用小画家开启图片后，用滴管点想要的颜色，到上面工具栏，色彩 → 编辑色彩 → 定义自订色彩，就可以找到此颜色的 RGB 数值。
