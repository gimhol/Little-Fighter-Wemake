## 1. 角色

请先打开 lf2 改档器，打开文件，在 lf2 的目录下找到 data 文件夹（建议先将 lf2 整个文件夹复制一份，避免改错）。在 data 文件夹中打开你想要改的角色，如 davis 的档案名字为 davis.dat，davis_ball.dat 则为 davis 的气功波档案。本篇是关于角色的档案，请先打开一个角色档案。

#### 特别发现：锁码与破解

强化网页的强化版是如何锁码的？仅是在人名之前加上中文字而已。写入中文字会导致编辑器读不到档案（并非所有的字都会），因此就像锁码一样。锁码的话会造成自己也无法改，除非你有另存未锁码的，不然以后你也不能再修改了。

破解方法（会破解的人大概也没几个）：故意先让 lf2.exe 执行时角色的 dat 档出错（可以先将其中一张图移开让它图取不到），它会告诉你出错并终止。然后再去看 data 资料夹中的 temporary.txt，它显示出的就是这个错误的 dat 档的内容。

#### 1.3.2 下一个帧编号 next

1. `next: 0` 是不断重复此动作，`hit*?` 的 0 是指没有设定。
2. `next`、`hit*?` 999 是指回到随机动作。
3. `next`、`hit_?` 1000 是消失。
4. `next: 1280` = rudolf 的隐形（使用隐身和变化术也会影响到分身）。
5. `next: -???` 会反向进行第 ??? 个 frame。
6. `next: 1200~1299` 是隐形。

##### kind

| 2 | 捡武器 |

##### fall「击倒系数」

角色都记录着一个「击倒数值」。「击倒数值」最大值为 70，最小值为 0。当角色每次被攻击时，「击倒值」将会减去「击倒系数」。

| fall | 效果 |
| ---- | ---- |
| 0 | 敌人只动一下 |
| 30 | 打两下敌人就晕 |
| 40 | 打一下往后退，打第二下就倒地 |
| 60 | 打一下晕眩，打第二下就倒地 |
| 70 | 必定倒地 |

- **vrest 15** = 同一个 frame 打到人的中间间隔时间（vrest 越小，同一个 frame 就会打到越多下）。如 Davis 的升龙霸，原本 vrest 只有 10，若改的更低，则会造成如强化网页的神龙拳的连击效果。
  - > [!NOTE] vrest 值最低只能是 4，更低的话打到人会卡住。
- **arest**（vrest 无效）= 一攻击到一个人，多久后才能再打一个人。
- **bdefend 60** = 破挡的机会（即打破敌人防御的机会）。bdefend 60 打一次就破挡；同 fall，如值是 16 则 16+16+16+16 大于 60，所以值是 16 时打敌人 4 下就破挡。bdefend 100 则完全挡不住，就算按挡也会让你直接被打到，连破挡的动作都跳过。且有防御效果的角色（如 Julian、Knight、Louis）也防不住；道具也会直接被毁掉（不论道具的 HP 有多少）。
- **injury 40** = 杀伤力（即损害敌人 hp 多少；玩家的 hp 是预设值的 500）。

**effect 特效**（在 injury 后面加上以下 effect，仅限于 kind 0 时有作用）：

| effect | 说明 |
| ------ | ---- |
| 0 | 拳击 |
| 1 | 利器攻击 |
| 2 | 着火 |
| 3 | 结冰 |
| 4 | 穿过敌人（仅能打中 type 1、2、3、4、5、6 的物件） |
| 5（或以上） | 没效果，也打不中任何东西 |
| 20 / 21 / 22 | 定身火 |
| 30 | 定身冰 |

> [!NOTE]
> - effect 可以加上负号（有效果但无声音）。
> - 若要加大攻击的 z 轴范围，只要在 effect 或 injury 的后面加上 `zwidth ??` 即可（没有 effect 就是加在 injury 的后面，若有 effect 则加在 effect 的后面）。
> - itr_end = 身体攻击动作结束。

**特别说明：大范围攻击**

```text
itr
kind 0  x -x  y -x  w x  h x  dvx ?  dvy ?  fall ?  vrest ?
bdefend ?  injury ?  zwidth x  effect ?
itr_end
```

x 数值越高则范围越大，? 数值是看自己高兴填写的。

### 1.4 bdy 解说

```text
bdy
kind 0
x 26  w 35   （受攻击前 ~ 后的距离）
y 12  h 66   （受攻击上 ~ 下的距离）
bdy_end
```

- bdy = 身体（受攻击的部分）开始；bdy_end = 身体结束。
- 若要消耗 mp 只要在 `<FRAME>` 之后的第一行结尾加上 `mp ??` 即可。
  - > [!NOTE] 若 mp 为 1000 以上则会变成扣 hp，如 firen 的大轰炸是 4300，就会扣 40 点 hp 及 300 点的 mp。
- 声音：只要在第一行与第二行之间插入 `sound data/???.wav` 即可。

### 1.5 wpoint 解说

若 frame 中有 wpoint 如下：

```text
wpoint
kind ?  x ?  y ?  weaponact ?  attacking ?  cover ?  dvx ?  dvy ?
dvz ?
wpoint_end
```

wpoint 是指此动作若拿着武器时则武器会是哪一个。

| 字段 | 说明 |
| ---- | ---- |
| x、y | 武器的位置座标 |
| weaponact | 武器的第几个 frame |
| attacking | 此时武器有否攻击性（0 是无攻击，1 是站着时的攻击，2 是跳时的攻击，3 是冲时的攻击，4 是冲跳时的攻击） |
| cover | 0 是你会盖住武器的图示，1 是武器会盖住你的图示 |
| dvx、dvy、dvz | 武器会往 x、y、z 座标移动多少 |

wpoint_end = 武器指令结束。

### 1.6 bpoint 解说

```text
bpoint
x 43  y 38
bpoint_end
```

- bpoint = 流血指令开始；bpoint_end = 流血指令结束。
- x、y = 嘴角的位置。
- > [!NOTE] hp 少于 1/3 时，嘴角才会流血。

### 1.7 抓人

若要抓起敌人，则要在 itr 中写入：

```text
itr
kind ?  x ?  y ?  w ?  h ?  vrest ?
catchingact ??? ???  caughtact ??? ???
itr_end
```

- catchingact：指抓住敌人后自己跳到第几个 frame（需重复写两次）。
- caughtact：指抓住敌人后敌人跳到第几个 frame。

或者在 cpoint 中写入：

```text
cpoint
kind ?  x ?  y ?  vaction ?  aaction ?  taction ?
injury ?  hurtable ?  decrease ?  throwvx ?  throwvy ?
throwvz ?  throwinjury ?
另外有 fronthurtact ?  backhurtact ?  dircontrol ?
cpoint_end
```

| 字段 | 说明 |
| ---- | ---- |
| kind | 抓人状态，1 是抓人，2 是被抓的（必须配合，1 抓 2 的，否则抓不起来） |
| x | x 座标，与被抓的 x 座标配合 |
| y | y 座标，与被抓的 y 座标配合 |
| vaction | 敌人的 act |
| aaction | 按 A 时自己跳到的 act |
| taction | 按 →A 时自己跳到的 act |
| injury | 被抓的敌人受伤量（正值是受伤+停格，负值是受伤不停格） |
| hurtable | 敌人会不会被人打到？（0 不会，1 会）※但 vaction 在 133~144 的敌人不会被打到 |
| decrease | （负值）抓住的时间减少值（总抓住的时间值 301/? = 抓住的时间） |
| throwvx | 丢出去的 x 速度 |
| throwvy | 丢出去的 y 速度 |
| throwvz | 丢出去的 z 速度（要按 ↑↓ 才会丢斜的） |
| throwinjury | 被丢者的受伤量（※ -842150451 不知是什么…） |
| fronthurtact | 正面被打后的 act |
| backhurtact | 背面被打后的 act |
| dircontrol | 控制方向（按着 → 进入此动作会向右转，负数则会相反） |

cpoint_end = 抓人指令结束。

**throwinjury 完全说明**

> [!NOTE]
> - throwinjury 不能为 0，否则自己会消失。
> - -1 是变成被抓者的 id（样子），如 Rudolf，之后可按 DJA 变回来，若想再变回去则只能用 state 501。
> - 可惜的是会无法使用按 DJA 会使出的招式（会变回来）。
