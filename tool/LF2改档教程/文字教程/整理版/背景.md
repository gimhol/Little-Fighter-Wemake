## 基本信息

| 字段 | 名称 | 描述 | 示例 |
| ---- | ---- | ---- | ---- |
| name: $1 | 名称 | | name: Template1 |
| width: $1 | X 轴宽度 | | width: 1600 |
| zboundary: $1 $2 | Z 轴范围 | $1 = 上边界，$2 = 下边界 | zboundary: 370 510 |
| shadow: $1 | 影子路径 | | shadow: bg/template/1/shadow.bmp |
| shadowsize: $1 $2 | 影子的尺寸 | $1 = 宽，$2 = 高 | shadowsize: 37 9 |

> [!NOTE] 原文写作「shandow / shandowsize」，应为「shadow / shadowsize」之笔误，此处已修正。

## layer

| 字段 | 名称 | 描述 | 示例 |
| ---- | ---- | ---- | ---- |
| layer: $1 | 开始 | $1 = 图片文件路径 | layer: bg\sys\gw\s.bmp |
| transparency: $1 | 图片黑色区域是否透明 | 0 = 不透明，1 = 透明 | transparency: 0 |
| width: $1 | | | |
| x: $1 | | | |
| y: $1 | | | |
| cc: $1 | | | |
| c1: $1 | | | |
| c2: $1 | | | |
| loop: $1 | | | |
| rect: $1 | | | |
| layer_end | 结束 | 结束无冒号 | |

> [!NOTE] 原文写作「transpparency」，应为「transparency」之笔误，此处已修正。

layer 是有照顺序的，最后面叙述的（玩时）显示在最前面。

> [!NOTE] `layer_end` 不能加冒号（:）。

## 字段详细说明

| 字段 | 说明 |
| ---- | ---- |
| transparency | 透明度（图片黑色部分，0 不透明，1 透明） |
| width | 794 是不会动（图片在整场移动距离 = ?-794） |
| x | x 座标 |
| y | y 座标，最高点 110 |
| loop | 多少距离放一个图片 |
| cc | 多少时间循环一次 |
| c1 | 循环内出现的时间 |
| c2 | 循环内结束的时间 |

示意图：

```text
←╮
╰→→→→→→→→→→→→╯
c1→出现→c2 cc
```

- **rect**：色彩填满。
  - width：宽度（从 x 座标算起）
  - height：高度（从 y 座标算起）

## 攻击范围

### 一般状态下，例如

```text
itr:
kind: 0 x: 40 y: 5 w: 35 h: 45 dvx: 9 dvy: -9 fall: 70 arest: 15 bdefend: 60 injury: 40
itr_end:
```

### 攻击全部场地，例如

```text
itr:
kind: 0 x: -7777 y: 64 w: 10101 h: 45 dvx: -5 dvy: -44 fall: 1070 vrest: 300 bdefend: 116 injury: 40 zwidth: 1887
itr_end:
```

简单的说：

- **x** 是后面的距离（超过身体图片用 - 表示）
- **w** 是前面的距离
- **y** 是上面的距离（超过身体图片用 - 表示）
- **h** 是下面的距离
- **zwidth** 是宽度
